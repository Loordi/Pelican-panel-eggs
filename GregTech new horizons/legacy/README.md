# Legacy eggs

These files are historical or version-specific variants kept for reference. Use the universal [`Pelican-GTNH-egg.json`](../Pelican-GTNH-egg.json) for new installations.

- `Pelican-GTNH-2.8.X-egg.json` is a snapshot of the previous 2.8.x-focused main egg.
- `Pelican-GTNH-2.8.X-twist-space-technology-egg.json` is the old GTNH 2.8.4 and Twist Space Technology 0.7.16 variant.

Legacy eggs may not receive new compatibility fixes or features.
